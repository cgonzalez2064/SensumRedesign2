Relaciones y reglas

Qué pasa con los datos relacionados cuando se borra un registro. Se borra también (CASCADE) para lo que solo existe por esa cuenta, como sus sesiones; queda sin dueño (SET NULL) para lo que debe conservarse, como la actividad o los prospectos. Las relaciones lógicas apuntan a archivos o guardan ids como texto: el panel las cuida, la base no.
